# El Pollo Loco

A browser-based jump-and-run game built with vanilla JavaScript and object-oriented programming.

## Live Demo

[pollo-loco.lutz-boelling.de](https://pollo-loco.lutz-boelling.de)

## About

Control Pepe through the world of El Pollo Loco. Collect coins and bottles, dodge enemies, and defeat the final boss. The game runs entirely in the browser with no frameworks or libraries.

## Features

- Object-oriented JavaScript architecture
- Modular class-based structure (player, enemies, collectibles, boss)
- Collision detection and game loop
- Sound effects and animations

## Tech Stack

- JavaScript (ES6+)
- HTML5 Canvas
- CSS3
